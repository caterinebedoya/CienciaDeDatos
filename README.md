# 
# Ciencia de Datos

Colección de notebooks en Python orientados al análisis de datos con pandas y a la aplicación de modelos de aprendizaje automático, desde métodos clásicos como la regresión lineal y los árboles de decisión hasta redes neuronales con Keras y TensorFlow.

Los notebooks se desarrollaron como laboratorios del curso **Aprendizaje Estadístico** del Instituto de Física de la Universidad de Antioquia (semestre 2025-1).

- **TensorFlow / Keras**: construcción y entrenamiento de redes neuronales.
- **[scikit-learn]**: modelos clásicos de aprendizaje automático (regresión, árboles de decisión, SVM).
- **[NumPy / Matplotlib]**: cálculo numérico y visualización.

## ▶️ Cómo ejecutar

1. Clona el repositorio:
   ```bash

   ```
2. Instala las dependencias:
   ```bash

   ```

